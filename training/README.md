  # Training notebooks
  Research notebooks used for the ablation study in the paper (Phases 1-7 and the
  mobile deployment evaluation). They were run on Kaggle (2x T4) with the public
  AgriVision dataset attached, and are shared as a research record, not as a
  one-click pipeline. Run them in phase order. Some paths point to private Kaggle
  models and must be replaced with your own checkpoints. A cleaned, reproducible
  version is planned.
